# research/

採否未決の調査・比較検討メモを置く場所です。

## 書くもの

- 複数の選択肢を比較したい技術選定（ライブラリ・アルゴリズム・アーキテクチャ）
- 実装に着手する前の検証・PoC のメモ
- 採用しなかった案とその理由

## 書かないもの

- 採用後の正式仕様（→ `docs/spec/` に書く）
- 採用後の実装詳細（→ `docs/arch/` に書く）
- 完了タスクの履歴（→ `docs/task/`）

## ライフサイクル

1. 調査開始時に `{topic-slug}.md` を作成
2. 比較表・結論・採否を記載
3. 採用案が `docs/spec/` / `docs/arch/` に正式化されたら、調査メモは結論部だけ残して詳細は削除するか、ファイル自体を削除する

陳腐化した調査メモを放置しないこと。
