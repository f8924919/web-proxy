このフォルダはテスト戦略・実行方法・ルールを管理します。コード変更時にデグレードが発生していないかを継続的に確認することを日常運用としています。

## 実行コマンド

```bash
# 全テスト実行
npm test

# 詳細出力
npm test -- --verbose

# カバレッジ計測
npm test -- --coverage

# 特定テストのみ実行
npm test -- --testPathPattern=<path>

# 単一 realm での実行環境 smoke（node --test の別レーン・policy.md §1.2）
npm run test:realm
```

---

## テストフレームワーク

| ツール             | 用途                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| Jest               | テストランナー（既定レーン）                                           |
| Jest（--coverage） | カバレッジ計測                                                         |
| `node --test`      | 単一 realm での実行環境 smoke（別レーン。[policy.md](policy.md) §1.2） |
