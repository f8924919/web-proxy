# アプリ概要

[← 目次](index.md)

## 概要

web-proxy は [proxyium.com](https://proxyium.com/ja/) を参考にした Web ベースのプロキシサービスです。

ユーザーがブラウザ上で URL を入力すると、Next.js サーバーがターゲットサイトへリクエストを中継し、レスポンスをユーザーへ返します。アクセス制限のある環境から外部 Web サイトを閲覧可能にすることを主目的とし、個人・小規模チームのユーザーを対象としています。

---

## 主な機能

- URL 入力フォームからターゲットサイトへのプロキシ中継
- HTML コンテンツの書き換え（リンク・フォームの相対パスをプロキシ経由 URL に変換）
- CSS / 画像 / スクリプトなど静的アセットの中継

---

## 動作環境

| 項目              | 要件                                          |
| ----------------- | --------------------------------------------- |
| OS                | Linux / macOS / Windows（Node.js が動く環境） |
| ランタイム / 言語 | Node.js 18 以上 + TypeScript                  |
| その他依存        | npm（パッケージ管理）                         |
