## 概要

ホーム画面で入力された URL を受け取り、プロキシ経由でターゲットサイトを表示する画面。

- ルート: `/browse`
- クエリパラメータ: `url`（必須、`encodeURIComponent` でエンコードされた URL）
- ファイル: `src/app/browse/route.ts`（未作成）
- レンダリング: **Route Handler**（生 HTML レスポンスとして返す。React を介さない）

## コンポーネント仕様

### アドレスバー

- 現在表示中の URL（デコード済み）を表示・編集できる入力フォーム。
- 送信すると `/browse?url=<encodeURIComponent(target)>` へ遷移（URL を差し替え）。
- ホーム画面と同じ「`http` 未入力時に `https://` 補完」ルールを適用。
- 表示する URL を `value="…"` 属性へ埋め込む際は、`& < > " '` をすべて HTML 実体参照へエスケープする。URL は `new URL` 正規化済みで属性ブレイクアウトは塞がれているが、出力エンコードの欠落は XSS（CWE-116）につながり得るため、防御の深さとして一括エスケープを行う（#137）。

### コンテンツエリア

- Route Handler がターゲット URL を fetch し、HTML を書き換えて生 HTTP レスポンスとして返す。
- アドレスバーは `<body>` 先頭に HTML スニペットとして注入する。ビューポート上部に固定表示し（`position: fixed`）、ターゲットの CSS（`body{height:100%}` 等）に依存せずスクロール中も常に表示される。直後のスペーサーでコンテンツがバーに隠れないようにする（#108）。
- 書き換えルール詳細は [プロキシ機能仕様](../features/proxy.md) を参照。

## ルーティング・パラメータ

| パラメータ | 型     | 必須 | 説明                                                |
| ---------- | ------ | ---- | --------------------------------------------------- |
| `url`      | string | ○    | プロキシ対象の完全 URL（`encodeURIComponent` 済み） |

---

## エラーハンドリング

| 状況                                 | 動作                                                 |
| ------------------------------------ | ---------------------------------------------------- |
| `url` パラメータなし                 | ホーム（`/`）へリダイレクト                          |
| URL のパース失敗                     | エラーページ表示（「URL が正しくありません」）       |
| SSRF ブロック対象                    | エラーページ表示（「アクセスできない URL です」）    |
| ターゲット到達不能（タイムアウト等） | エラーページ表示（「サイトに接続できませんでした」） |
| ターゲットが 4xx / 5xx               | ステータスコードをそのまま返す（透過）               |
