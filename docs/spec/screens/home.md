---

## 概要

ユーザーが閲覧したい URL を入力し、プロキシ経由で遷移するための起点画面。

- ルート: `/`
- ファイル: `src/app/page.tsx`

---

## 画面レイアウト

```
┌─────────────────────────────────────┐
│                                     │
│          Web Proxy                  │  ← h1
│   アクセスしたい URL を入力してください  │  ← サブテキスト
│                                     │
│  [ https://example.com        ] [移動] │  ← URL 入力フォーム
│                                     │
└─────────────────────────────────────┘
```

---

## コンポーネント仕様

### URL 入力フォーム

| 項目           | 仕様                    |
| -------------- | ----------------------- |
| 入力タイプ     | `text`                  |
| プレースホルダ | `https://example.com`   |
| 最大幅         | 560px（ページ中央揃え） |
| 送信ボタン     | ラベル「移動」          |

### 送信時の動作

1. URL が空の場合は何もしない。
2. URL が `http` で始まらない場合、`https://` を先頭に付与する。
3. `/browse?url=<encodeURIComponent(target)>` へクライアントサイドリダイレクト（`window.location.href`）。

---

## バリデーション

| 条件              | 動作                                         |
| ----------------- | -------------------------------------------- |
| 空文字            | 送信をキャンセル（エラーメッセージなし）     |
| `http` 以外の入力 | `https://` を自動補完して送信                |
| 不正な URL 形式   | （ドラフト段階：未定。サーバー側で検証予定） |

---

## 状態管理

| 状態  | 型       | 初期値 | 説明                   |
| ----- | -------- | ------ | ---------------------- |
| `url` | `string` | `""`   | URL 入力フィールドの値 |
