# 実装ブリーフの雛形

`implementer` へ実装を委譲するときは、**このファイルを `.brief/<slug>.md` へ複写して埋め**、起動プロンプトには
**パスと「このファイルを読め・文脈を失ったと感じたら読み直せ」だけ**を書く（取り決めの正本は
[git-workflow.md](../../../docs/git-workflow.md) §5.2「実装の委譲」）。

`.brief/` は `.gitignore` 済みで、追跡されない。**scratchpad には置かない**
（セッション固有なので `/clear` した瞬間に消える）。
